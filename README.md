REDLINER wiki frontend project 
##
REDLINER wiki is an authentic, clean and responsive wiki project for the fast-paced roblox game REDLINER. It includes information on general item statistics, along with basic and advanced strategies.
***
Features: 

* **Clean red, black and white aesthetic:** Matching the actual game, utilising transparent dark cards and a blurred background to reinforce aesthetic.

* **Consistent Dual-Column layout:** Uses CSS flexboxes to create a dual column page layout, used to provide text content and relevant visual content side-by-side.

* **Responsive interactions:** Uses CSS hover and transition elements to create micro-interactions with response in features such as the home button, the wiki link and the navigation bar.

***
Technologies used:

**HTML5**

**CSS3**
***
Installation instructions:

1. Create a folder in your local system environment

2. Download this repository to said folder in your local system

3. Launch the index.html file in any modern browser (such as Chrome, Edge, Firefox etc.) to view the live environment.
